# Changelog

All notable changes to the AHCECR309 Learning Resource will be documented in this file.

## [2.0.0] - August 2026

### Added
- **Module 5: Conducting the Inspection** - Complete practical workflow module
  - Pre-inspection preparation and research
  - Survey methods (meander, transect, quadrat, targeted)
  - Documentation techniques (photos, field notes, GPS)
  - Post-inspection and reporting
  - 3 interactive practice scenarios
- **Module 6: Biosecurity & Environmental Context** - NEW comprehensive module
  - Biosecurity threats and hygiene practices
  - Abiotic elements (soil, climate, hydrology, geology)
  - Microorganisms and their role in ecosystem function
  - Ecosystem services (provisioning, regulating, supporting, cultural)
  - Local industry impacts (forestry, agriculture, mining, tourism)
  - 3 interactive practice activities
- **Module 1 enhancements** - Added sections on:
  - Abiotic elements (soil, climate, hydrology, geology)
  - Microorganisms (mycorrhizal fungi, decomposers, nitrogen fixers, pathogens)
- **Module 2 enhancements** - Added sections on:
  - Ecosystem services with Tasmanian examples
  - Local industry impacts on Tasmanian ecosystems
- **Module 5 enhancements** - Added sections on:
  - Biosecurity threats and hygiene practices
  - Reconciliation of field observations against existing records
  - Reporting biosecurity hazards
- **ARIA accessibility features** - Screen reader support, keyboard navigation
- **Breadcrumb navigation** - Clear "where you are" indicators
- **Completion animations** - Celebratory animations when modules are completed
- **Full Learner's Guide PDF** - 120+ page comprehensive guide available for download
- **Version badge and changelog** - Professional version tracking
- **Expanded progress tracking** - Now supports 6 modules
- **Downloadable resources section** - All PDFs in one place
- **Expanded flashcards** - Added biosecurity flashcard

### Changed
- Complete visual redesign with modern, professional UI
- Consolidated CSS into shared stylesheet
- Consolidated JavaScript into shared app.js
- Reorganized files into logical folder structure (`modules/`, `css/`, `js/`, `resources/`)
- Updated module badges to show progress status
- Enhanced mobile responsiveness
- Improved navigation with tab indicators
- Updated keyboard shortcuts to support 6 modules (Ctrl+1 to Ctrl+6)
- Updated footer with version 2.0.0 and changelog link

### Fixed
- Module progress tracking across all 6 modules
- Resource download functionality
- Pademelon image display
- User Guide navigation links
- Quiz and activity feedback
- Completion animations triggering correctly
- Module 5 progress tracking

### Removed
- Duplicate CSS and JavaScript from individual files
- Redundant code across modules
